# ✨ TheInvite

A highly interactive digital invite that uses playful UI/UX psychology to guarantee a "yes". 

## 💡 What it does
Instead of a boring text message, this app lets users select their perfect date vibe and locks it in. 
* **The "No" Trap:** Rejecting the invite mathematically shrinks the "No" button. Click it too many times, and the app throws a dramatic fainting fit and switches to a hypnotic mind-control screen.
* **The "Yes" Celebration:** Accepts trigger a CSS party background, a confetti explosion, and floating polaroids. 
* **Seamless Export:** Automatically grabs the user's selected vibes and generates a ready-to-send WhatsApp message.

## 🛠️ Tech Stack
Built entirely with **Vanilla JavaScript, HTML5, and CSS3** (No external frameworks). Highlights include DOM manipulation, array state tracking, and complex keyframe animations.
